- `lenovo-loq.png`
- `motorola-g18.png`
- `boat-headphones.png`
- `hp-pavilion.png`
- `lenovo-loq-2.png`

PNG is supported! Transparent PNGs look great with the existing clean card styling.
If any PNG file is not yet added, the website automatically falls back to clean CSS illustration placeholders.
